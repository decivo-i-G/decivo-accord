# @decivo/accord-adapter-code

The code surface: reads CSS custom properties, Tailwind v4 `@theme` and shadcn/ui, finds hard-coded colours and lengths, and maps them to tokens.

Part of [decivo Accord](https://github.com/decivo-i-G/decivo-accord#readme), the register for design decisions that people and agents check against. Most teams use the command line [`@decivo/accord-cli`](https://www.npmjs.com/package/@decivo/accord-cli) or the MCP server [`@decivo/accord-mcp`](https://www.npmjs.com/package/@decivo/accord-mcp) rather than this package directly.
